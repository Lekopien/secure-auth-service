Security

Authentication done properly

A zero-dependency Node.js auth service: scrypt password hashing, a hand-written HS256 JWT implementation, refresh-token rotation with theft detection, account lockouts and hardened HTTP headers.

View sourceRun it locally

Highlights

scrypt hashing

Per-user random salt, tunable cost stored in the hash string, constant-time comparison.

JWT from scratch

HS256 with node:crypto; algorithm pinned so alg=none and confusion attacks fail.

Refresh rotation

Refresh tokens are single-use, stored hashed, and reuse revokes the whole session family.

Brute-force defence

Lockout after repeated failures with Retry-After; same error for unknown users to stop enumeration.

Timing-safe

Unknown emails still run a real hash comparison, so response time doesn't reveal accounts.

Hardened responses

no-store, nosniff, CSP, HSTS, frame denial, body size limits.
